# 大学城场景 + 校园路网导航 — 操作指南

**环境：** ROS 2 Humble + Isaac Sim 6.0.1 + slam-nav + fast_lio2  
**目标：** 大学城 USD 中沿 OSM 路网发目标并行驶。

---

## 最短成功路径（先看这里）

1. 按 **§四** 起四个终端（Isaac → bringup → `start_outdoor.bash -s` → RViz）
2. 终端 3 出现 `Managed nodes are active` 后，再等日志 **`heading LOCKED`**  
   （`-s` 会 `auto_drive` 直行解锁；无头模式不一定「看见」车动，以日志 / status 为准）
3. RViz **只用「2D Goal Pose」**，目标点在路上且距当前 **>20 m**
4. 立刻检查：`ros2 topic hz /plan` 与 `ros2 topic hz /cmd_vel_nav` **必须有频率**
5. 有红线 `/campus_path` 但无 `/plan` → **Nav2 没跟线**，见 §八 Q1

## 一、架构

```
终端1 Isaac  → /clock /livox/* /odom_gt /joint_states
终端2 bringup → /gps/fix /livox/lidar ； /cmd_vel → /joint_command
终端3 室外栈  → 定位 + Nav2 + campus_nav
终端4 RViz   → 「2D Goal Pose」→ /campus_goal_pose
```

**速度链（整条有数据车才会动）：**

```
campus 规划 → Nav2 → /cmd_vel_nav → smoother → /cmd_vel_smoothed
  → collision_monitor → /cmd_vel → swerve → /joint_command → Isaac
```

| 现象 | 含义 |
|---|---|
| 有红线 `/campus_path`，无 `/plan`、无 `/cmd_vel_nav` | 路网 OK，**Nav2 未跟线** |
| 灰色道路底图 | AerialMap 瓦片，**不是**蓝色 OSM |
| 蓝色细线 | `/campus_network`（MarkerArray） |

## 五、航向锁定（发目标前必做）

航向只在 **终端 3 运行时** 累计（看 `/Odometry` + `/gps/fix`，≥约 3 m）。

| 做法 | 说明 |
|---|---|
| **推荐（`-s`）** | `auto_drive` 自动直行 → 日志 `LOCKED` |
| **手发速** | 发到 **`/cmd_vel_smoothed`**（CM 输入端），**不要**发 `/cmd_vel` |
| **禁止** | `ros2 lifecycle set /collision_monitor deactivate` → `CRITICAL FAILURE`，整段 Nav2 崩 |

如何确认锁定：

```bash
ros2 topic echo /heading_align/status --once   # data: locked
# 或看终端 3 日志：heading LOCKED and north-aligned
```

手发速（outdoor 必须在跑）：

```bash
source ~/navi-sim-code-backups/slam-nav-20260901T135838+0800/setup_ros_local.sh
ros2 topic pub /cmd_vel_smoothed geometry_msgs/msg/Twist \
  "{linear: {x: 0.25}}" -r 10
# 终端 3 出现 LOCKED 后 Ctrl+C
ros2 topic pub /cmd_vel_smoothed geometry_msgs/msg/Twist "{}" --once
```

话题对照：

| 话题 | 用途 |
|---|---|
| `/heading_align/status` | `locked` / `unlocked` |
| `/Odometry` | FAST-LIO；航向 baseline |
| `/odom_gt` | Isaac 真值；仅测底盘位移 |

仅测底盘（不跑导航）：可 Ctrl+C 停终端 3，再 `ros2 topic pub /cmd_vel ...`。

## 六、发路线

1. 四终端就绪；`heading` = **locked**
2. RViz **只点「2D Goal Pose」**（勿点 Nav2 Goal / Start）
3. 目标在路上，距当前 **>20 m**（2–3 m 几乎看不出）
4. 立刻检查（有频率才算跟线）：

```bash
ros2 topic hz /plan          # 全局路径
ros2 topic hz /cmd_vel_nav   # 控制器输出
```

5. 终端 3 应有 `Begin navigating ...`，且**不要**刷 `missed deadline to stop`
6. 导航时**不要**再开键盘遥控（会误推进航点）

**有 `/campus_path`（红线）≠ 车会动**；必须有 `/plan` + `/cmd_vel_nav`。

## 七、关闭与清栈

关闭：RViz → 终端 3（Ctrl+C）→ bringup → Isaac（`q`）

规划卡死 / Nav2 异常时：

```bash
pkill -f "start_outdoor|nav2_container|component_container_isolated|campus_route_planner"
sleep 3
# 再 ./start_outdoor.bash -s ，重新等到 LOCKED
```

## 八、常见问题

### Q1：有路网红线，车不动 / `hz /cmd_vel_nav` 无输出

1. 是否误用了 **Nav2 Goal**？（只用 2D Goal Pose）
2. `ros2 topic hz /plan` 有无？无 → Nav2 规划卡住，**清栈后重开终端 3**
3. `ros2 topic hz /livox_scan2` 有无？无 → CM 刹停
4. `heading` 是否 `locked`？
5. 目标是否太近（<10 m）？

日志若 `compute_path_through_poses ... missed deadline`：规划器死锁，软重启无效，必须 `pkill` 后重开 outdoor。

### Q2：没有蓝色路网

- 灰色 = 卫星底图；蓝色 = `/campus_network`
- **RViz 保持打开**，重启终端 3，等 5–10 s
- 勾选 `/campus_network`；可关 AerialMap 防遮挡

### Q3：`Managed active` 后仍 `baseline 0.0/1.5`

- outdoor **刚重启**，baseline 归零；等 `auto_drive` 或手发 `/cmd_vel_smoothed`
- 无头模式可能「看不见」前进，以 **status=locked** 为准
- **禁止** deactivate `collision_monitor`

### Q4：DDS / 无话题

- 每终端 `source setup_ros_local.sh`
- Participant 超限：确认 `cyclonedds_localhost.xml`，并**重启 Isaac**

### Q5：TF 冲突

- bringup **不要** `with_odom_tf:=true`

### Q6：勿用命令

| 勿用 | 原因 |
|---|---|
| `start_navi.sh -s` | 会杀 outdoor |
| RViz「Nav2 Goal」 | 与 campus `navigate_through_poses` 冲突 |
| `deactivate collision_monitor` | Nav2 整栈 CRITICAL FAILURE |
| 终端 3 运行时 `pub /cmd_vel` | 被 CM 覆盖（解锁用 `/cmd_vel_smoothed`） |
| `unset CYCLONEDDS_URI` | DDS 不一致 |

### Q7：其它

- elevation / CuPy：仿真用 `-s` 即可（已跳过）
- `osmium`：`sudo apt install -y python3-pyosmium`
- Humble 插件名：见 `param_outdoor_sim.yaml`（`/` 与 `::` 混用）

## 十、仿真侧改动摘要（维护者）

| 项 | 内容 |
|---|---|
| `start_outdoor.bash -s` | `param_outdoor_sim.yaml`：无 terrain_layer、全局窗 100 m、A* |
| `gps_heading_align` | `sim:=true` 时 `auto_drive`，发 `/cmd_vel_smoothed` |
| `campus_network` | TRANSIENT_LOCAL + 每 10 s 重发；`outdoor.rviz` Transient Local |
| `nav2_batch_max_poses: 1` | 每次只喂 1 航点，减轻规划卡死 |
| `cloud_to_2d_laserscan` | `require_elevation_grid:=false` 时仍发 `/livox_scan2` |
| `setup_ros_local.sh` | Domain 7 + localhost + participant 上限 120 |

速度链：`/cmd_vel_nav` → `/cmd_vel_smoothed` → `/cmd_vel`（CM 独占）→ `/joint_command`。
